# スマブラ Logger

スマブラSPの対戦結果を、スマホからワンタップで Notion に記録するためのアプリ。

**入力は自作の画面、保存先と閲覧は Notion** という分担。Notion のモバイルアプリでデータベースに行を足すのは手数が多いが、この画面ならキャラを2回タップして勝敗を押すだけで済む。

公開URL: https://smash-logger-app.pzeo581e.workers.dev

---

## 画面

タブは4つ。キーボードの `1`〜`4` で切り替わる。

### 1. 対戦

- 自分と相手のファイターをタイルから選ぶ（全86体、本家のファイター番号順）
- 直近100戦でよく使ったキャラ TOP5 は上段に大きく表示
- 同じタイルをもう一度押すと選択解除
- 勝敗（`W` / `L`）、対戦種別（スマメイト / オンライン / オフライン / その他）、メモを添えて送信
- 下部に直近の記録を表示

### 2. メモ

気づいたことを書き留める。1行目がタイトル、2行目以降がページ本文になる。日付とタグ（カンマ区切り）を付けられる。Notion 側に無いタグは自動で作られる。

### 3. 履歴

Notion から直近100戦を読み込んで集計する。

- KPI（対戦数 / 勝率 / 勝-敗 / 連勝・連敗 / 直近10戦 / 記録日数）
- 自分のキャラ別成績
- 相手のキャラ別成績（勝率の低い順＝苦手キャラ）
- 日別の推移、対戦種別ごとの比較
- レート推移グラフ

### 4. 設定（⚙）

- **接続** … URL と合言葉、接続テスト、アイコンの再取得
- **回線チェック** … 対戦前のラグ確認。Cloudflare の速度測定サービスを直接叩き、遅延・ゆらぎ・下り速度を測る
- **モード** … スマメイトモードの切り替え
- **表示** … 名前表示、列数（6〜12）、アイコンサイズ（26〜64px）、TOP5表示、キャラ保持
- ショートカット一覧、Notion と外部サイトへのリンク

## スマメイトモード

オンにすると全体が篝火テーマ（炎の配色）に変わり、対戦タブにレート記録欄が加わる。

- 期・現在レート・前回からの差分を表示
- 今日の戦績 / 勝率 / レート増減
- **送信1回で、対戦記録と期別レートDBの両方を更新する**（最終レート・最高レート・戦績を自動計算）
- 画面を詰めるため、アイコンを26px・名前オフに自動で切り替える（オフに戻すと元の設定に復帰）

## ショートカット

| キー | 動作 |
|---|---|
| `1`〜`4` | タブ切り替え |
| `W` / `L` | 勝ち / 負け |
| `Ctrl` + `Enter` | 送信 |
| `/` | キャラ検索へ |
| `Esc` | 選択をすべて解除 |

文字入力中は `Ctrl+Enter` と `Esc` のみ有効。

## 仕組み

```
ブラウザ ──→ Cloudflare Workers ──→ Notion API
           （静的ファイル配信 + API中継）
```

Notion のトークンはブラウザに置けない（見られてしまう）ため、間に Cloudflare Workers を挟んでいる。フロントと API は同一ドメインなので CORS の問題は起きない。

GitHub の `main` に push すると自動でデプロイされる。詳細は [DEPLOY.md](./DEPLOY.md)。

### ファイル

```
index.html          入力フロント（1ファイル完結。HTML + CSS + JS）
fighters.js         ファイター86体のデータ（id / name / no）
worker/src/index.js API ロジック
wrangler.toml       デプロイ設定（環境変数もここ。Secret は除く）
.assetsignore       静的公開から除外するファイル
DEPLOY.md           デプロイ手順
```

### API

| メソッド | パス | 用途 |
|---|---|---|
| POST | `/log` | 記録の書き込み（`type`: match / memo / rate） |
| GET | `/meta` | アイコンURL、直近100戦の使用回数 |
| GET | `/icon?id=` | Notion の画像を中継（1日キャッシュ） |
| GET | `/history?limit=` | 対戦履歴とメモ履歴 |
| GET | `/rate?season=` | 期別レートの現在値 |

`/icon` 以外は合言葉（`APP_TOKEN`）が必要。

### Notion 側のデータベース

| DB | 役割 |
|---|---|
| 🎮 スマブラ対戦記録 | 1行1戦。勝敗・自分・相手・種別・レート・変動・期 |
| 🗒 スマブラメモ | メモ・日付・タグ |
| 👤 ファイター（スマブラSP） | 86体。アイコンはカスタム絵文字で登録 |
| 📈 スマメイト 期別レート | 期ごとの最終・最高レート、戦績 |

## つまずいたところ

後から同じ問題に当たったとき用のメモ。

- **アイコンが1体しか表示されない** … Notion にアップロードした画像の URL は5分で失効する。**カスタム絵文字**なら期限なしの公開URLになるので、そちらを使う
- **自分が空欄で登録される** … 統合や削除で消えたページIDが端末に残っていた。Notion API は**存在しないIDのリレーションを無言で捨てる**ため、エラーも出ない。Worker 側で書き込み後に検証して警告を出すようにした
- **変更が反映されない** … ブラウザキャッシュ。`fighters.js?v=86` のようにバージョンを付ける
- **HTTP 405 が返る** … ⚙のURLに `https://` を書き忘れると自分自身に POST される。自動補完で対処
- **Notion API の制約** … 1リクエスト100件まで、集計はできない（クライアント側で計算）、`number` 型に `format` を渡すとエラー
